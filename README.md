# Simple Linear Regression From Scratch

## Overview

This repository demonstrates the implementation of **Simple Linear Regression** from scratch using Python. The project focuses on understanding the mathematical foundations behind linear regression rather than relying on machine learning libraries.

Throughout this project, I learned how a linear regression model makes predictions, measures errors using a cost function, calculates gradients, and updates parameters using gradient descent to find the optimal values of **weight (w)** and **bias (b)**.

## Topics Covered

* Linear Regression Fundamentals
* Prediction Function
* Cost Function (Mean Squared Error)
* Gradient Calculation
* Gradient Descent Algorithm
* Parameter Optimization
* Finding Optimal Weight (w) and Bias (b)
* Data Visualization

## Learning Objectives

By completing this project, I gained practical experience with:

* How linear regression models work internally
* The role of the cost function in measuring model performance
* How gradients guide parameter updates
* How gradient descent minimizes prediction error
* Training a model without using built-in machine learning algorithms

## Project Workflow

1. Load and visualize data
2. Make initial predictions
3. Calculate the cost function
4. Compute gradients
5. Apply gradient descent
6. Update model parameters (w and b)
7. Repeat until convergence
8. Evaluate final predictions

## Results

The model successfully learns the optimal values of **weight (w)** and **bias (b)** using gradient descent, enabling accurate predictions on the dataset.
